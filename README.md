# Silêncio na Estação · Página de vendas

Exportação da versão 6, em 07/11/2026. HTML, CSS e JavaScript puros, com imagens locais. Não precisa instalar dependências nem executar build.

## Subir no GitHub

1. Extraia o ZIP no computador.
2. Crie ou abra seu repositório no GitHub.
3. Em **Add file → Upload files**, envie o conteúdo extraído, incluindo a pasta `images`.
4. Deixe `index.html`, `style.css` e `app.js` na raiz do repositório. Não envie apenas o ZIP.
5. Clique em **Commit changes**.

## Publicar com GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta **/ (root)**. Salve e aguarde o GitHub mostrar o endereço da página. A disponibilidade do Pages depende da visibilidade do repositório e do plano da conta.

Os caminhos das imagens e arquivos são relativos e funcionam também em páginas hospedadas em uma subpasta de repositório.

## Arquivos

- `index.html`: conteúdo e estrutura.
- `style.css`: cores, fontes e layout responsivo.
- `app.js`: seleção de produtos, resumo, cronômetro e janelas.
- `images/`: imagens usadas pela página.
- `favicon.svg`: ícone do site.
- `.nojekyll`: arquivo para servir os arquivos estáticos diretamente.
